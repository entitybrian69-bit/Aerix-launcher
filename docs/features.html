Features

Everything in the box

Aerix is one app: it installs Minecraft, runs it, and gets out of the way. Here is what is actually in it — no roadmap, no promises, just the shipped build.

Instances

One per world, one per setup

Every instance is a sealed box: its own game version, loader, mods, configs, renderer and memory. Break one and the others do not care.

Every loader

Vanilla, Fabric, Forge, NeoForge, Quilt and OptiFine, with the loader version chosen for you when there is a sensible default.

Every version

Releases, snapshots and old betas, from the newest 1.21+ back to the versions people still build on.

Its own renderer

An old phone can run one instance on GL4ES and a newer one on Zink, without changing anything globally.

Its own memory

Allocate what the mods need per instance instead of one global number that suits none of them.

Its own controls

Different layouts for different games: a PvP pad on one instance, a modded keyboard-heavy layout on another.

Loader's own mark

Instance cards show the loader's logo, and packs installed from Discover carry the publisher's artwork.

Renderers

Twelve backends, one picker

Android GPUs and drivers vary wildly, so no single renderer suits every phone. Aerix ships several and lets you change them per instance — and in 1.5.5 a renderer whose library is missing is replaced instead of taking the launch down with it.

Emesis, bundled

The default. A GL-to-GLES translation layer that works on the widest range of Adreno and Mali devices, and needs no plugin APK to be installed.

Then, if it does not run

Try Zink on a phone with a solid Vulkan driver, LTW for modern versions, or GL4ES for older ones. The full lineup and what each is for is on the renderer page.

Controls

Eleven themes, and an editor that respects them

Every control can wear a piece of animated pixel art, with its own press effect, haptic and key sound. The theme travels with the layout file, so a setup you share arrives looking the way you made it.

Theme, or not

Off is a chip like any other, and Move it freezes the animation entirely if you want a still control.

Feel and sound

Each theme carries a haptic pattern and a system key click, both switchable, neither needing a permission or an asset.

Apply to all

Pick one for the control you are editing, then push it across the whole layout in one tap.

Custom controls

Every button is yours

Place and size

Drag to move, drag the handle to resize, with snapping to edges and to other controls.

Keys and specials

Up to four keycodes per button, plus mouse buttons, scroll, keyboard toggles, GUI and menu.

Drawers and sticks

Sub-buttons in pull-out drawers, and joysticks with deadzone, size and absolute tracking.

Pictures

Crop an image into any button as its background, or style it with a colour, stroke and corner radius.

Sharing

Layouts are plain JSON, so they import and export cleanly between devices and other launchers.

Per-instance

Keep a keyboard-heavy layout for modded packs and a thumb-friendly pad for vanilla survival.

Accounts

Sign in once, switch whenever

Microsoft, Ely.by and offline accounts live side by side, each with its own skin, cape and model. In game, the account panel can switch: confirm the restart and the launcher comes back as the account you picked, with the game already starting.

Microsoft

The official sign-in, in the browser or in-app, with the token stored on your device only.

Ely.by

For the skins and capes people use outside the official service.

Offline

Any username, for testing modpacks and for playing without a network.

Skin wardrobe

Skins, capes and a character that turns

Equip a skin from storage or from the skin search, change Wide/Slim, add a cape, and keep saved presets per account. The character on the right of the in-game menu is that same skin — drag it and it spins under your thumb.

Presets per account

Keep several looks and switch between them without re-importing the file.

It reaches the game

The skin, cape and model are written where the game reads them, so what you pick is what you see in game.

Look

31 wallpapers, no seams

25 photographs and six recorded HD clips, plus any clip you import yourself. The accent colour follows what you choose, and nothing is stretched over the interface with a strip of blur down the middle.

Content

A browser that installs

Search CurseForge and Modrinth from inside the launcher, filter by version, loader and category, then install straight into the instance you are building.

Mods

With the loader it needs and its dependencies.

Modpacks

Publisher artwork, resolved loader and version.

Shaders

For the versions and renderers that can use them.

Resource packs

Installed into the selected instance.

In game

A menu you can actually use

Two halves, nothing in the way: actions down the left, and the account you are playing as down the right, on a character you can spin. The FPS readout hides while it is open.

Resume first

The way out is the first, largest target — not buried under nine other buttons.

Log output, in game

Read the log without leaving the game, which is what you want when a mod misbehaves.

Screen recorder

Capture a clip of the game from the same menu.

Custom keycode

Send a key the layout does not have, without editing anything.

Quick settings

The handful of things worth changing mid-session.

Force close

When a world will not let go, close the game cleanly instead of fighting the task switcher.

Ready?

Install it in about a minute

Download the APK, allow the install, pick an account, make an instance. The guide walks through each step.
