# Aerix Launcher 1.5.3 — a guide on first launch

## What it is

Open the launcher for the first time and it now introduces itself, the same way Zalith Launcher 2
does: a short card, then the interface dims with a rounded cut-out around each important control
while a card explains it.

Seven steps:

1. **Welcome** — what this tour is, and that it will not show again.
2. **Create an instance** — the ＋ in the rail.
3. **Your library** — where instances live, and what holding one does.
4. **Pick, then play** — the action panel with PLAY and its gear.
5. **Renderers** — Emesis is bundled; if a game will not start, this is the setting to change.
6. **Make it yours** — the wallpapers page, the 25 photographs and the 12 real clips.
7. **That is everything** — add an account, then create the first instance.

Tapping anywhere advances. The cut-out follows the highlighted control exactly, because each control
publishes its own bounds rather than the guide guessing at layout — so it stays correct in portrait,
landscape, compact and expanded rail. The last step persists a flag and the tour never runs by itself
again.

## Showing it again

**About → Show the guide again** replays it from the first step, for anyone who skipped it or wants
a refresher.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
