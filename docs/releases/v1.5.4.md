# Aerix Launcher 1.5.4 — no more loading screen

## The loading screen is gone

The black screen with the spinner is removed completely — not just its text. The game activity now
opens straight onto the game screen, so from the first moment you see:

- your controls, laid out where you put them,
- the Aerix overlay button, and
- the game drawing itself as soon as it is ready.

Nothing covers the game while it boots. There is no spinner to wait on, nothing to tap through, and
nothing left of ours drawing over the game once it starts.

The "Waiting for a game window to appear…" and "If you are stuck here, the game might have crashed"
lines that used to sit on that screen are gone with it.

## Wallpaper while the game starts

The switch is in the Aerix menu, directly under the logo — "Use wallpaper as loading background",
with an on/off switch.

- **Off** (the default): black behind the controls while the game starts, exactly as before.
- **On**: your wallpaper — a photograph, one of the recorded animations, or a clip you imported —
  is drawn instead of that black until the game window appears. It is the same wallpaper component
  the launcher uses, so blur and accent match what is set.

The wallpaper sits **behind** the control buttons and the Aerix menu button, so both stay visible
and both stay usable while it is showing. Because the switch is in the menu, it can be flipped while
the game is still starting and the change lands immediately.

The moment the game window appears, the wallpaper is removed, and any video decoding with it stops
— nothing of it runs while you play, so it cannot cost a frame.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
