# Aerix Launcher 1.5.4 — the loading screen, cleaned up and made yours

## The overlay text is gone

"Waiting for a game window to appear…" and "If you are stuck here, the game might have crashed" are
removed. The screen is now just the spinner and, when you turn it on, your wallpaper.

## Use wallpaper as loading background

The switch is in the in-game Aerix menu, directly under the logo — open the menu and it is the first
thing there. The loading screen itself stays a clean black screen with a spinner and nothing else.

- **Off** (the default): the screen is plain black until the game window appears.
- **On**: the loading screen shows the wallpaper applied in the launcher — a photograph, one of the
  recorded animations, or a clip you imported. It uses the same wallpaper component as the launcher,
  so it always matches what is set, including the blur and the accent.

The choice is remembered, and applies from the next launch — a loading screen only exists while the
game is starting, so there is nothing for it to change mid-game.

**No cost when it is off, or once the game is up.** Off - the default - nothing is created at all:
no composable, no view, nothing on the startup path. Switched off again, the wallpaper layer is
disposed rather than just hidden. That matters because it means the setting cannot cost a single
frame of gameplay: by the time the game is drawing, none of it exists.

As soon as the game window appears — the moment the Mojang logo comes up — the wallpaper is removed
and any video decoding with it stops, before the game draws its first frame.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
