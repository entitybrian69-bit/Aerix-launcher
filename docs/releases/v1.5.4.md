# Aerix Launcher 1.5.4 — no more loading screen

## The loading screen is gone

The black screen with the spinner is removed completely — not just its text. The game activity now
opens straight onto the game screen, so from the first moment you see:

- your controls, laid out where you put them,
- the Aerix overlay button, and
- the game drawing itself as soon as it is ready.

Nothing covers the game while it boots. There is no spinner to wait on, nothing to tap through, and
nothing left of ours drawing over the game once it starts.

The "Waiting for a game window to appear…" and "If you are stuck here, the game might have crashed"
lines that used to sit on that screen are gone with it.

## Wallpaper while the game starts

The switch is in the Aerix menu, directly under the logo — "Use wallpaper as loading background",
with an on/off switch.

- **Off** (the default): black behind the controls while the game starts, exactly as before.
- **On**: your wallpaper — a photograph, one of the recorded animations, or a clip you imported —
  is drawn instead of that black until the game window appears. It is the same wallpaper component
  the launcher uses, so blur and accent match what is set.

The wallpaper sits **behind** the control buttons and the Aerix menu button, so both stay visible
and both stay usable while it is showing. Because the switch is in the menu, it can be flipped while
the game is still starting and the change lands immediately.

The moment the game window appears, the wallpaper is removed, and any video decoding with it stops
— nothing of it runs while you play, so it cannot cost a frame.

## The in-game menu, rebuilt

The Aerix menu now has two halves.

**Left:** the actions, top to bottom — **Resume game** first (in the accent, the way out), then
**Log output**, then Custom controls, Send custom keycode, Quick settings, In-Game Downloads,
Screen recorder, Force close game and the loading-wallpaper switch. Full-width rows, tall enough to
hit comfortably, all the way to the bottom of the column.

**Right:** the Aerix mark and title at the top, then the character the game is running as. Your own skin, cape and Wide/Slim model, turning a
full 360° — drag it, or flick it and it keeps spinning and settles. Under the figure is the account
name, and under that how that account signed in: **Microsoft**, **Ely.by** or **Offline**.

Tap the name and you get the list of accounts you have already made, with the one in play marked
*Current*. Picking one cannot take effect from inside a running game — the session is already
granted — so it answers with the reminder:

> You must be in the game dashboard in order to switch account

The frame-rate readout is hidden while the menu is open, so it cannot sit on top of the buttons.

## A smaller download for your phone

1.5.4 is also the first release built per architecture. Android phones only use one set of native
libraries, but the old single APK carried every set at once — which was most of its weight.

The release now ships:

| file | for |
| --- | --- |
| `Aerix-Launcher-1.5.4-arm64-v8a.apk` | every 64-bit phone — the one almost everyone gets |
| `Aerix-Launcher-1.5.4-armeabi-v7a.apk` | 32-bit phones |
| `Aerix-Launcher-1.5.4.apk` | universal, for x86 devices and as a fallback |

The in-app update popup picks the right one for your device automatically and shows which it chose
and how big it is. Nothing is removed from any build: the other architectures simply live in other
files. Both are signed with the same key, so installing over an existing Aerix Launcher is a normal
in-place update and your instances, accounts and wallpapers stay where they are.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
