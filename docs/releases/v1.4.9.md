The ten weather loops I added are removed. In their place are the **twelve clips you brought**:

The 25 photographs and the 25 drawn scenes are **untouched** — same places, nothing new added to
them, exactly as they were.

## Built to stay smooth

- **960×540, 24 fps, H.264 Main profile, level 3.1** — the profile every Android device decodes in
  hardware. Playing a wallpaper costs almost no CPU, which is what keeps the interface from stuttering.
- **Seamless loops** — the last half second of each clip is cross-faded into its first, so there is no
  jump when it restarts.
- **5.2 MB for all twelve**, down from 6.9 MB for the ten placeholders. The downloads are smaller than
  before: each loop is between 103 KB and 991 KB.

## Layout

**Add animation** moved up onto the same line as **Wallpapers** and **Animations**, so the grid starts
immediately — no separate row, no wasted space. The third-party credit line is gone, because the
footage is yours.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
