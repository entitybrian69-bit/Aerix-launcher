# Aerix Launcher 2.4.4

**This is the release that installs over 2.4.1 in place.** No uninstall, no lost worlds, no export.

## What was actually blocking it

Android does not let a multi-signed app move to a single-signed one. From AOSP
`SigningDetails.checkCapability`:

```java
if (oldDetails.mSignatures.length > 1) {
    // multiple-signer packages cannot rotate signing certs, so we must have an exact match
    return signaturesMatchExactly(oldDetails);
}
```

The published **2.4.1** carries two certificates: the current key, plus the retired key it was given so
that installs from 2.3.2 and older could move across without an uninstall. Because it has two signers,
Android demands the identical pair back. 2.4.2 and 2.4.3 carried the current key alone, so they were
refused with `INSTALL_FAILED_UPDATE_INCOMPATIBLE` every time - which is why nothing ever installed.

2.4.4 carries both certificates, exactly as 2.4.1 does. It installs straight over it.

## What to expect

- **On 2.4.1:** this installs over it and keeps everything. Instances, worlds, mods, accounts and
  downloaded runtimes are untouched.
- **On 2.4.2 or 2.4.3:** this installs over it too.
- **On 2.3.2 or older:** this installs over it directly too, because it still carries the retired key.

## The trade this release makes, stated plainly

Every future release is now signed with both keys, permanently - not just this one. That is unavoidable:
once an app carries two signers, every later update must carry the same pair or Android refuses it.

The retired key is not secret. It was committed to this public repository along with its password,
which is why it was retired in the first place. Anyone with repository access can build an APK that
installs over a launcher on your device. Signing releases with it again is a real loss of update
authenticity, accepted because the alternative was stranding every 2.4.1 install with no update path
that does not delete data.

The full reasoning, the alternatives that were considered, and the rules that still hold are in
[`docs/signing-policy.md`](https://github.com/entitybrian69-bit/Aerix-launcher/blob/v3_openjdk/docs/signing-policy.md).

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed.
Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK
for another supported architecture. Checksums are in `SHA256SUMS`.
