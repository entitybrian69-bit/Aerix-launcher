# Aerix Launcher 1.3 — Our biggest update yet

A major step forward for recording, in-game chat, launcher updates and discovering Team Aerix projects.

## In-game Performance Recorder
- Open **A-logo → Screen recorder** without leaving Minecraft.
- Independently choose **240p, 360p, 480p, 720p or 1080p** and **15, 24, 30, 48, 60, 90 or 120 FPS**. Unsupported hardware encoder combinations cannot start; FPS is a target, not a guarantee.
- Choose **Game audio**, **Microphone**, or **Game audio + microphone**. Your audio choice is remembered. Game-only never opens the microphone, and single-source modes retain full volume.
- Hardware H.264 video with stereo AAC audio, recording indicator, Stop & save controls and an ongoing Android recording notification.
- MP4s save to **Movies/Aerix**, with low-storage protection, recovery of abandoned pending recordings and improved audio/video timestamps.

## Smoother in-game chat and keyboard handling
- Fixes for Space, IME composition, bulk text rewrites and pending chat text across keyboard connection changes.
- Better preservation of chat text during temporary focus loss and keyboard hiding.
- Bounded keyboard-opening retries and cooldowns to avoid repeated focus/restart loops.

## Smarter launcher updates
- A new automatic update popup for genuinely newer published stable launcher releases, with **Download**, **Cancel**, and **What's new** inside the window.
- Downloading or dismissing acknowledges that version across app restarts. It won't prompt again for that same release; a newer release can prompt again.
- Manual update checking, retrying and installing remain available in Settings. Downloads retain size, checksum, package and signing-certificate validation.
- Update checks run while the launcher is resumed, not during Minecraft gameplay. They are periodic checks, not instant server-push notifications.

## Our other new releases
- A dedicated Team Aerix project showcase with a narrower, more compact page, smaller headings and tighter spacing.
- First featured project: **Aetherium (Fabric)** by **Team_Aerix**.
- Its action opens the exact CurseForge project in Aerix's existing **Discover detail page**, retaining live files, instance selection, dependencies and normal installation.
- Verified CurseForge project ID **1749327**, with exact-slug checks to avoid the NeoForge edition or similarly named projects.
- Fabric compatibility information and rendering-mod conflict warnings appear on the card. Performance descriptions are project claims, not launcher benchmarks.

## Download
- **Aerix-Launcher-1.3.0.apk** — recommended full APK, including the Java runtime.
- **Aerix-Launcher-1.3.0-noruntime.apk** — smaller alternative without the bundled runtime.

Install over your existing Aerix Launcher installation. Do not uninstall or clear app data; back up important worlds and settings before upgrading.

## Important recording notes
Recording requires **Android 10 or newer**, Android audio permission and fresh screen-capture consent. Game-only still needs Android's RECORD_AUDIO permission, but does not open the microphone. Older supported launcher devices can continue using the launcher without this recorder.

Internal game audio can be silenced by Android/OEM policy, the native audio backend or muted Minecraft audio. If Game-only remains silent, try **Settings → Game → Forcefully use OpenSL for audio**, then restart Minecraft. The recorder never silently substitutes microphone sound for internal game audio. Headphones are recommended when mixing both sources.

Hardware encoder support does not guarantee smooth 1080p/120 FPS gameplay or recording. Device-specific audibility, A/V sync, thermal behavior and visual layouts still require physical-device testing.

## Validation
The release is built through Android CI: regression tests, full APK, no-runtime APK and native FPS checks. Automated checks do not replace the device tests described above.
