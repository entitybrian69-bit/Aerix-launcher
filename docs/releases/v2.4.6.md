# Aerix Launcher 2.4.6

**This release installs over 2.4.5, 2.4.1, and 2.3.2 in place** with `versionCode 20406` and
permanent double-signing, preserving all instances, worlds, mods, accounts, and downloaded runtimes.

## What changed

- **Resource-pack loading & priority fixes:** Fixed single-root nested resource-pack `.zip`
  unwrapping (`MyPack/pack.mcmeta` + `__MACOSX`), `options.txt` priority merging so user resource
  packs always stay above `Aerix-Client-Pack.zip`, and moved the Aerix pack stamp into
  `config/.aerix_pack_stamp` instead of leaving dotfiles inside `resourcepacks/`.
- **WebView isolation, rejoin button & stutter fixes:** Isolated WebView data directories per
  process, restored the floating **A** menu button when rejoining the game, and tuned JVM GC,
  thread affinity, and overlay I/O to eliminate device-dependent game stutters.
- **Zero-copy hardware screen recorder & renderer cleanup:** Redesigned in-game screen recording
  for hardware capture and removed deprecated MobileGlues components cleanly.
- **Aerix Launcher PC (`2.4.6`):** Added the cross-platform Electron + TypeScript desktop edition
  for Windows (`x64`), Linux (`x64`), and macOS (`arm64` & `x64`), featuring Microsoft, Aerix Auth,
  and Offline accounts, Fabric/Forge/NeoForge/Quilt & Aerix Client PC, Modrinth & CurseForge
  Discover, and automatic Eclipse Temurin Java management.
- **Double-signed permanently (carried forward from 2.4.4 / 2.4.5):** Carries both the current
  signing certificate and the retired certificate so existing installs on 2.4.5, 2.4.1
  (`INSTALL_FAILED_UPDATE_INCOMPATIBLE` against single-signed builds), and 2.3.2 or older update
  straight over in place without an uninstall or lost worlds.

## What to expect

- **On 2.4.5, 2.4.4, 2.4.3, 2.4.2, or 2.4.1:** installs over it in place and keeps all instances,
  worlds, mods, accounts, and downloaded runtimes.
- **On 2.3.2 or older:** installs over it directly too, because it still carries the retired key.

## The signing trade, stated plainly

Every release from 2.4.4 on is signed with both keys, permanently. The retired key is public in
this repository (`tests/aerix_legacy.p12.b64`), which means anyone with repository access can build
an APK that installs over an existing launcher. See
[`docs/signing-policy.md`](https://github.com/entitybrian69-bit/Aerix-launcher/blob/v3_openjdk/docs/signing-policy.md)
for the full AOSP reasoning and rules that still hold.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed.
Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK
for another supported architecture. Desktop installers for Windows, Linux, and macOS are attached as
`Aerix-PC-*`. Checksums are in `SHA256SUMS` and `SHA256SUMS-PC.txt`.
