# Aerix Launcher 2.4.6

**This release installs over 2.4.5, 2.4.1, and older release builds in place**, adding the
1080p60 intro splash, landscape Modpack Browser and Import Controls redesigns, and fixes for
unresponsive buttons in the in-game screen recorder.

## What changed

- **1080p60 cold-start intro splash:** Plays the bundled 1080p60 `aerix_intro.mp4` cleanly via a
  hardware-accelerated `SurfaceView` + `MediaPlayer` controller on cold launch with smooth exit
  handoff into the launcher shell.
- **Landscape Modpack Browser & Import Local Modpack UI:** Rebuilt `SearchModFragment` in Aerix's
  smoky-glass Compose theme for landscape orientation with a unified search bar, `All` / `Modrinth`
  / `CurseForge` source filter pills, MC version filter chip, `Import Local` pill button, circular
  Home button, 2-column card grid, and glassmorphic version-picker install modal.
- **Landscape Import Controls UI:** Rebuilt `ImportControlActivity` in landscape (`sensorLandscape`)
  with a split smoky-glass card featuring a frosted gamepad format/status badge, filename validation,
  and preserved `POJAV` / `ZALITH` / `FCL` compatibility conversion.
- **Screen recorder button fixes:**
  - Tapping an FPS chip now auto-picks the closest compatible resolution instead of breaking
    `Start Recording`.
  - Pinned the header (`Close`) and footer (`Recordings`, `Start Recording`, `Stop & Save`) so
    buttons remain reachable on short landscape screens and inside system cutouts/insets.
  - Added a live `Record with controls` toggle during active recordings, released `GameView`
    pointer capture while the panel is open, moved recording list recovery & MediaStore publishing
    off the main thread, and added a `Stop` watchdog + idle broadcast fallback so `Stop & Save` and
    `● REC · Stop` never stay stuck.
- **Double-signed permanently (carried forward from 2.4.4 / 2.4.5):** Carries both the current
  signing certificate and the retired certificate so existing release installs (`2.4.5`, `2.4.4`,
  `2.4.3`, `2.4.2`, `2.4.1`, and `2.3.2` or older) update straight over in place without uninstalling
  or losing worlds, instances, accounts, or runtimes.

## What to expect

- **On 2.4.5, 2.4.4, 2.4.3, 2.4.2, or 2.4.1:** installs over it in place and keeps all instances,
  worlds, mods, accounts, and downloaded runtimes.
- **On 2.3.2 or older:** installs over it directly too, because it still carries the retired key.
- **On Nightly/Debug (`net.al.aerixlauncher.debug`):** Android treats testing builds as a separate
  package (`applicationId`), so release builds install alongside rather than over testing builds.

## The signing trade, stated plainly

Every release from 2.4.4 on is signed with both keys, permanently. The retired key is public in
this repository (`tests/aerix_legacy.p12.b64`), which means anyone with repository access can build
an APK that installs over an existing launcher. See
[`docs/signing-policy.md`](https://github.com/entitybrian69-bit/Aerix-launcher/blob/v3_openjdk/docs/signing-policy.md)
for the full AOSP reasoning and rules that still hold.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed.
Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK
for another supported architecture. Checksums are in `SHA256SUMS`.
