# Aerix Launcher 2.2.0 — Bedrock Home (Nightly)

Aerix 2.2.0 brings a Bedrock-inspired home screen rebuilt as an original Aerix composition — same layout language you know from Bedrock, rendered with Aerix glass and motion.

## What's new

- **Bedrock Home**: left notched cards (Shop · My skin · Play with friends), center draggable 3D doll with idle bob + fling physics, top utility icons, right promo card and bottom instance dock. Inspired by Bedrock's panorama, authored for Aerix — no Mojang textures copied.
- **Smooth feel**: spring entrance (staggered 0/70/140 ms), liquid-glass blur, scale-on-press, infinite bob, horizontal-drag rotation with exponential decay and idle slow-spin.
- **Instance dock 1:1**: blue START HERE card (Fabric · 1.20.1) + green Assets/Play panel with `×` and thin progress rail, plus yellow Open chest bar — matching both screenshots (93% downloading → Play).
- **Play with friends** → Socials, **My skin** → Accounts, **Shop** → Discover, **Find a party / Invite a friend** → Socials. Help FAB and `Open chest` → file manager.
- **Nightly channel**: version bump to 2.2.0, debug APK published on push via `aerix-debug.yml` (`net.kdt.pojavlaunch.debug`).

## Notes

- Original Aerix shapes/colors/motion; not a pixel asset rip. Background stays your Aerix wallpaper with a soft vignette.
- Smoothness varies by device (WebView for skin preview, Compose motion). No behavior change to launch, install, auth or renderers.
