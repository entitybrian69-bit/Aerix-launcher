# Aerix Launcher 2.2.0

Aerix Launcher 2.2.0 brings the Minecraft Java Servers tab, the Aerix account setup flow, world sharing with e4all, a refreshed launcher look, and one testing channel: Aerix Nightly.

## What's new

- **Servers tab:** save Minecraft Java servers, check their status, show server artwork and decorative banners, and arrange the list in a grid.
- **Aerix accounts:** a dedicated account setup page with Google sign-in (PKCE) and linked game profiles.
- **Authentication:** bundled authlib-injector refreshed for 26.3 offline skins, with the Aerix game session service wired into account setup.
- **World Sharing:** world invites connect to in-game friend chats, and the in-game menu installs supported e4all Android builds for hosting.
- **Launcher UI:** restored screenshot-inspired layout with glass surfaces, responsive scaling, launcher font styles and a new twilight wallpaper.
- **Resource packs:** safer inspection, animated download handling and smaller copies for large packs.
- **Aerix Nightly:** all non-release updates and testing now ship as `Aerix-Nightly.apk` on the `debug-latest` prerelease. It keeps the same package ID and signing key as the old debug build, so it installs over it and keeps its data. Stable releases stay under `v*` tags.

## Important notes

- Performance, recording, renderer and mod compatibility vary by device. These changes have not been verified on every Android device or GPU.
- World Sharing needs a supported game version, an ARM64 device, an internet connection and the separately operated relay. Vanilla local LAN remains available.
- FastClient, e4all, Fabric and other downloads require an internet connection and come from their own providers.
- Existing release installations can update in place only when the package ID, signing certificate and version code are compatible. The separate Nightly app does not update into the release app. Back up important game data before updating.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed. Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK for another supported architecture. Checksums are included in `SHA256SUMS`.
