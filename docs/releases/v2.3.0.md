# Aerix Launcher 2.3.0

Aerix Launcher 2.3.0 is the release where the launcher gets its own app ID, the memory ceiling stops fighting itself, the in-game overlay keeps the controls where you left them, and every recorded clip - finished or not - can be found and shared again.

## What's new

- **New app ID:** Aerix now installs as `net.al.aerixlauncher` instead of `net.kdt.pojavlaunch`. Game data, settings and instances are imported from an existing install on first launch, the old app is left untouched as a rollback, and a launcher update never overwrites the install it copied from.
- **One memory ceiling:** the launcher heap and the game heap are now budgeted from the same device reading instead of two independent guesses. A device that could never grant 6 GB says so instead of offering it, and the picker keeps a "Try 6 GB anyway" override for devices that can.
- **The A menu stays put:** releasing the A button inside the overlay keeps the menu where it was released. A hide decision now needs the gesture to start below the system status strip and a 240 ms hold, so a swipe past the top edge no longer blanks the controls mid-game. The small `A` entry sits below that strip, and an overlay the launcher did not hide says why on its own pill.
- **Mouse aim you can tune:** the sensitivity that scales both axes and the per-axis aim sensitivity are separate settings again, so mouse speed matches what you set. Cursor skins apply to the overlay and the custom cursor size slider works; a cursor recorded through the overlay plays back at the size it was drawn at.
- **Screen recordings, recovered and shared:** recordings land in a library you can import, share and delete from inside the launcher, with a recents row on Discover. A clip interrupted before it was finalised is kept as `-unfinished.mp4` instead of being lost.
- **Custom Vulkan drivers:** import a driver APK and pick it per instance, for GPUs the bundled driver handles poorly.
- **Max refresh rate:** a switch on the client page that reads back the mode the display actually bound to, so an unsupported request tells you instead of silently doing nothing.
- **Controller navigation:** the launcher UI can be driven with a gamepad.
- **Home and Discover:** Continue, Quick actions, Instances & servers and Activity, with the restored classic dashboard as the default home layout and the newer hero layout behind the Home layout switch.
- **Modpack search in the launcher:** results show their artwork, and Install now opens a window that lists only the versions the selected client can actually run - loader, environment and game version - and installs the pack into that client.
- **Cosmetics:** Discord activity is published before the sign-in check that used to suppress it, and chat typing is paced so long messages do not paste in one block. Trinkies cosmetics were retired for this release; the Fabric GameTest harness and the per-version runtime matrix they built stay.

## Important notes

- Performance, recording, renderer and mod compatibility vary by device. These changes have not been verified on every Android device or GPU.
- The app ID migration imports once, from a readable legacy install, and keeps the old app. Two installs can coexist; only the new one is updated by this release.
- Large heaps are still bounded by the device: 6 GB is offered only where the device can back it, and the override runs at your own risk.
- Custom Vulkan drivers come from their own providers and are loaded as-is.
- FastClient, e4all, Fabric and other downloads require an internet connection and come from their own providers.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed. Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK for another supported architecture. Checksums are included in `SHA256SUMS`.

Testing builds are no longer published as a debug APK: every non-release build ships as **Aerix Nightly** on the `debug-latest` prerelease. It keeps the debug package ID and signing key, so it installs over an existing debug build and keeps its data.
