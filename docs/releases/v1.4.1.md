# Aerix Launcher 1.4.1 — Updates download at full speed

## In-app updates are now much faster

- **Six connections instead of one.** The updater used to pull the whole APK down a single HTTP
  stream, which on a phone's link spends most of its time waiting — one stalled packet and the
  progress bar sat at 1 MB while nothing moved. The file is now cut into equal byte ranges and
  fetched over **6 connections at once**, up to **256 KB per read**.
- **Redirects are followed properly.** GitHub answers the download URL with a redirect to its file
  host, and a redirected request could lose its `Range` header, quietly turning a part download into
  a full one. The updater now resolves the redirect first, so every part asks the file host directly.
- **Stalls recover by themselves.** If a connection drops or closes early, that part resumes from
  the byte it reached — up to 4 attempts — instead of restarting the file or failing the update.
- **Lighter on the phone.** The check and every part request ask for `identity` encoding with
  caching off, parts are written straight into their own offset of the file (nothing is held in
  memory), and progress is reported at most ten times a second.
- **Checksum still verified.** The SHA-256 in the release is checked against the finished file
  before the installer is offered, and the package, version and signing certificate are validated
  exactly as before.
- **Cancel closes every connection**, not just the last one, so a cancelled download stops
  immediately.

Small files (under 4 MB) still come down a single connection, and a server that does not support
range requests falls back to a single buffered stream, so nothing regresses if GitHub ever changes
its behaviour.

## Everything from 1.4 is in here

This release carries the bundled **Proton** renderer (32-bit devices), the **Contribution** tab, the
download-target fix (one instance ticked instead of all of them), the clearer `needs 1.16.5` /
`Fabric only` badges and the corrected version labels (`Fabric 1.16.5`, not `Fabric 0.16.10`).

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. Same signing key as 1.3.6
and 1.4.0, so it updates in place.

- `Aerix-Launcher-1.4.1.apk` — full build with the Java runtimes embedded.
- `Aerix-Launcher-1.4.1-noruntime.apk` — smaller build without an embedded runtime; it downloads the
  runtime it needs.

Checksums for every attachment are in `SHA256SUMS`.
