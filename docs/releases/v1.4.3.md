# Aerix Launcher 1.4.3 — every wallpaper moves, and one switch controls it all

## All 25 wallpapers are animated

- **A slow drift on every wallpaper.** Each one pans and zooms gently, so the background is a
  living picture instead of a still one. It applies to the 25 bundled wallpapers *and* to a custom
  image you import.
- **Particles chosen from what the picture shows**, so nothing was hand-authored per wallpaper:
  petals on the five cherry and meadow scenes, embers on the two Nether scenes, snow on the two
  frozen ones, stars on the three night skies, fireflies in the lush caves and the Deep Dark,
  bubbles in the ocean monument, and sunlit motes everywhere else.
- **Nothing was added to the APK.** The particles are drawn at run time from the wallpaper's own
  identity, and the pictures stay the same ~100 KB JPEGs they were.

## The theme moves too

- The **accent pulses**, the **selected renderer tile glows**, and the **selected section in the rail
  glows** with it — for any theme, the 25 bundled ones or your own colour.
- The glow is a gradient, not a blur pass, so it will not stutter on a mid-range phone.
- Only the selected element animates. An idle screen costs what it did before.

## One button for all of it

**Settings → Appearance → Animated theme**, or the **Motion on / Motion off** button right on the
Wallpapers page. Both flip the same switch, and both apply on the next frame — there is no restart,
no reload, nothing to confirm.

Turning it off stops the accent pulse, the glow, the wallpaper drift and every particle at once.

It also steps aside automatically: if Android's own **"remove animations"** accessibility setting is
on, the launcher stays still.

## A blur meter that applies to everything

The Wallpapers page now carries a **Blur** slider next to the Motion button, and it governs every
wallpaper rather than one of them. It writes the same setting as the Appearance page, so the two
always agree.

- On Android 12 and newer this is a real GPU blur.
- Below Android 12 there is no blur effect in the platform, so the wallpaper is decoded at a
  fraction of the screen resolution and drawn back up — the same soft look, and the meter still
  works on every device this launcher supports.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. Signed with the same key
as 1.4.2, so it updates in place.
