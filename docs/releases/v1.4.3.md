# Aerix Launcher 1.4.3 — a theme that moves, and a switch that stops it

## The accent breathes

The colour theme is no longer flat. Whatever accent you pick — any of the 25 wallpaper themes or
your own custom colour — now drives motion everywhere it already appeared:

- **Selected renderer tiles pulse and glow.** The accent on the chosen tile breathes gently and the
  tile carries a soft bloom around its lining.
- **The selected item in the rail does the same**, so the section you are in is alive instead of
  merely tinted.
- The glow is drawn as a gradient, not a blur pass: it costs almost nothing and will not stutter on
  a mid-range phone, which is where a blur would.

Only the *selected* thing animates. Nothing else on screen moves, which is what keeps it looking
deliberate rather than busy.

## One switch, no restart

Settings → Appearance → **Animated theme**.

Flip it off and the launcher is still on the next frame: no reload, no relaunch. Elements that are
not selected never start an animation in the first place, so an idle screen costs exactly what it
did before this release.

Two things force it off on their own, so it can never fight the system:

- **Android's "remove animations" accessibility setting** — if you have asked the system to reduce
  motion, the launcher respects it and stays still.
- Turning the switch off is remembered across restarts.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. Signed with the same key
as 1.4.2, so it updates in place.
