# Aerix Launcher 2.1.0

Aerix Launcher 2.1 adds a client chooser, FastClient support and World Sharing, alongside recorder and instance improvements.

## What's new

- Choose between Aerix Client and Fast client 2.0 from the Clients page. FastClient is provided by Mx Inspire, with links to their YouTube and Discord.
- Install FastClient for Minecraft 1.21.11, 26.1.2 and 26.2 as separate instances. New installations download compatible Fabric Loader, Fabric API, Lithium and Entity Culling releases. Existing FastClient instances are not changed automatically.
- Use World Sharing from the in-game menu with supported e4all Android builds. Hosting requires a supported version, an ARM64 device and an internet connection; the relay is operated separately. Vanilla local LAN remains available, but vanilla internet sharing isn't supported.
- Recordings are saved to the running instance's `recordings` folder, with in-game options to open or share them. The recorder has encoder fallback and safer MP4 finalization; unfinished files may be retained for recovery.
- Fixed an overflow in the control editor, removed the Library filter, and improved instance-specific renderer selection.

## Important notes

- Performance, recording and renderer compatibility vary by device. These changes and the bundled client/mod combinations have not been verified on every Android device or GPU.
- The optional Mesa library download failed during the build because its required GitHub token was unavailable. Mesa-dependent renderers such as Zink may be missing or not work in this release. MobileGlues is separate.
- A reported `Mx Inspire.zip` texture-pack reload failure could not be diagnosed conclusively from the supplied log. If you encounter it, try disabling the pack and provide the pack and crash report for investigation.
- Minecraft 26.x, the newer cape path, and World Sharing have not been verified across all devices. Animated capes are currently a local-client effect and are not synchronized to other players.
- FastClient and Fabric/mod downloads require an internet connection. The World Sharing relay is outside Aerix's control.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed. Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK for another supported architecture. Checksums are included in `SHA256SUMS`.

Existing release installations can update in place only when the package ID, signing certificate and version code are compatible. The separate debug app does not update into the release app. Back up important game data before updating.
