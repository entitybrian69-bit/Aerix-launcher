# Aerix Launcher 1.4.2 — updates that actually move

## The update download is no longer one slow stream

The updater used to pull the whole APK down a single connection with small reads. On a phone that
means the download spends most of its life waiting, and one hiccup anywhere in the middle stalls
everything behind it — a 130 MB update could crawl for minutes.

- **Six connections at once.** The file is cut into byte ranges and each range is fetched on its own
  connection, so the link is filled instead of idled. Reads went from 64 KB to 256 KB.
- **Each range lands in its own place.** Parts are written straight into their offset of the file,
  so nothing is buffered in memory and the file is whole the moment the last part arrives.
- **A dropped range resumes, not restarts.** The old download started from zero on any failure; a
  part that loses its connection now continues from the byte it reached, up to four attempts.
- **The redirect is resolved first.** GitHub sends the download to a file host; asking that host
  directly is what makes the byte ranges hold, instead of every part coming back as the whole file.
- **Checksums and the size check stay.** The finished file is still verified against the release's
  SHA-256 and its announced size before anything is offered for install.
- **Cancel really cancels.** Cancelling closes all six connections instead of leaving them draining
  the cache in the background.
- Servers that do not support byte ranges still work: the download falls back to a single stream.

## You can see the speed

The update dialog now shows the live rate next to the progress — `84.2 / 130.8 MB · 12.4 MB/s` — so
it is obvious whether the network or the launcher is the one holding things up.

## Measuring it

Debug builds only: Settings → **Check for updates** → when it says there is no newer release, a
**Test download speed** button downloads the published APK through the exact same code path and
reports the time and rate it achieved. It never installs anything.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. This build is signed with
the same key as 1.4.1, so it updates in place.

Two APKs are attached:

- `Aerix-Launcher-1.4.2.apk` — full build with the Java runtimes embedded.
- `Aerix-Launcher-1.4.2-noruntime.apk` — smaller build without an embedded runtime; it downloads the
  runtime it needs and updates the no-runtime edition in place.

Checksums for every attachment are in `SHA256SUMS`.
