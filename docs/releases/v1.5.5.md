# Aerix Launcher 1.5.5 — controls that move, and a switch that switches

## 25 control themes

Wait — eleven. The number moved while the release was being cut: the first build drew coloured
panels, and they were replaced by something much better before this went out. **Eleven pieces of
pixel art**, each one a control you can wear.

Open the control editor, pick a control, and scroll to the bottom: **Control themes**. The strip is
the artwork itself — rounded thumbnails, named underneath — so what you tap is exactly what the
control will wear.

| Theme | What it does |
| --- | --- |
| **Tea Party** | drifts slowly, ripples out from the touch |
| **Rocket Ride** | the rockets climb, the control lifts under your finger |
| **Nebula** | drifts, glowing edge on press |
| **Stardust** | the stars twinkle at their own pace |
| **Aurora** | slides sideways, a highlight sweeps across |
| **Galaxy** | the swirl turns slowly, glows when pressed |
| **Moonrise** | moonlight breathes behind the label, flashes on press |
| **Event Horizon** | the accretion ring turns, a ring runs off the edges on press |
| **Static** | jitters like interference |
| **Star Cross** | every star twinkles independently |
| **Comet Grid** | a comet crosses on its own, and again on press |

- **Off** is the first chip and gives the plain control back.
- **Apply to all controls** puts the one you just picked on every control in the layout.
- **Move it** turns the ambient motion off and leaves a completely still themed control.
- **Feel it** and **Hear it** switch the haptic tick and the key click that each theme carries.
- Picking a theme paints the control immediately and plays one press, so you judge it in place.

Themes are saved with the layout as a per-control id. A layout made before this version, or one that
names a theme a later update drops, simply draws the stock control — nothing breaks.

## Switching accounts from inside the game

The in-game account panel used to answer with *"You must be in the game dashboard in order to switch
account"* — from anywhere, including the dashboard. It now switches.

Tap your name under the character, pick an account, confirm the restart, and the launcher comes back
signed in as that account with the game already starting. The confirmation says what it costs: the
world you are in is closed, because a running game keeps the session it was launched with — the only
real switch is a new session. Picking the account you are already on does nothing.

## A renderer that cannot load no longer kills the launch

A renderer taken from a plugin APK names its OpenGL library by absolute path. When that path is
wrong, LWJGL throws on the render thread as the game window is created, and the game dies during
startup — before the renderer picker is reachable.

Now the library is checked **before** the JVM starts:

- a renderer whose library is missing is replaced by the bundled **Emesis** — the same translation
  layer most plugins provide — so you stay on the renderer you meant to use;
- if Emesis is the one that failed, the launch falls back to **GL4ES** instead of dying;
- a plugin whose declared libraries are not all there is refused with a log line, not a crash.

If a game ever refuses to start, this is the reason to try another renderer, or a lower resolution.

## Wallpapers: six HD clips, and you can see them first

The high-resolution animation pack is now **six** clips — Autumn Mountains, Butterfly Garden, Sakura
Field, **Flower Forest Train**, Night Sky and Wisteria Lake — downloaded on demand at full quality.

- Every animation card shows a real frame from the clip instead of a placeholder.
- The loops are cut to **one and two seconds** with no re-encode: shorter, not smaller quality.
- Nothing is decoded while you play; the clips only run on the launcher screens.

## Smaller things

- Instances show the loader's own mark — Fabric, Forge, NeoForge, Quilt.
- Modpacks installed from Discover carry the publisher's own artwork.

## Which file to download

| file | for |
| --- | --- |
| `Aerix-Launcher-1.5.5-arm64-v8a.apk` | every 64-bit phone — the one almost everyone gets |
| `Aerix-Launcher-1.5.5-armeabi-v7a.apk` | 32-bit phones |
| `Aerix-Launcher-1.5.5.apk` | universal, for x86 devices and as a fallback |

Each of those also has a `-noruntime` edition: the same launcher with the Java runtime fetched on
demand, so the download itself is much smaller.

The in-app update popup picks the right file for your device automatically and shows which it chose
and how big it is. All builds are signed with the same key.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. Instances, accounts, skins,
controls and wallpapers stay exactly where they are.
