# Aerix Launcher 2.0.0

Aerix Launcher 2.0 brings the Aerix Client and launcher updates together in a public release.

## Highlights

- Aerix Client includes an in-game menu, cosmetic selections, HUD options and version-specific mod setup.
- The launcher includes social profile, skin and cape controls, along with messaging and presence features.
- Instance-specific memory settings and updated launcher artwork are included.
- Discord Rich Presence is configured to request the current Aerix logo.

## Compatibility notes

Minecraft 26.x support is experimental. The newer animated-cape path and waving integration have
not yet been verified in a real game on every device; animated capes are currently a local-client
effect and are not synchronized to other players. Performance and renderer compatibility depend on
the device and game version. Discord may also use the application icon configured in its Developer
Portal when it cannot show the supplied presence image.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as
needed. Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the
universal APK if you need another architecture. Checksums are included in `SHA256SUMS`.

Existing installations can update in place only when the package ID, signing certificate and version
code are compatible. Back up important game data before installing a major update.
