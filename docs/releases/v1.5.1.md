# Aerix Launcher 1.5.1 — less to download

## One APK per phone architecture

A phone uses one set of native libraries; the APK was carrying every set. The build now produces a
separate APK for each architecture, and the testing download is the 64-bit one:

| | before | now |
|---|---|---|
| 64-bit phone (arm64) | 74.8 MB | about 28 MB |
| 32-bit phone (v7a) | 74.8 MB | about 25 MB |

Nothing is removed. Every renderer, every wallpaper and every feature is still there — the libraries
for other CPUs simply live in other files. If the main APK will not install, use
`Aerix-Launcher-debug-v7a.apk`.

## The 25 wallpaper photographs are WebP

They were JPEG; WebP at the same visible quality is smaller. 2.9 MB became 1.9 MB with no change on
screen.

## Checked, and already done

Native libraries are already stripped of debug symbols, so there was nothing to win there — the
symbols are not in the build.

## Left alone on purpose

Java code shrinking (R8) would save more, but PojavLauncher leans on reflection heavily and things
fail silently when it goes wrong. Not worth it without long testing. The renderer libraries the UI
never offers could save another 10–18 MB per architecture, but that means removing renderers, which
is not happening.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**.
