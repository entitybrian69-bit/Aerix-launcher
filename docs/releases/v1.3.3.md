# Aerix Launcher 1.3.3 — Chat correction update

## Chat editing
- Correcting a letter no longer makes the launcher delete and retype the unchanged rest of the message.
- Preserve the common prefix and suffix, edit only the changed range, and track the game caret between successive corrections.
- Handle single-letter deletion/replacement, forward deletion, composing-word corrections and Unicode code points.
- Synthetic IME edits no longer inherit Ctrl/Shift/Alt shortcut flags. Physical-key forwarding is unchanged.

## Experimental renderer removed
- Remove the experimental RustGL renderer used in test builds, all bundled native libraries, its settings entry, dedicated diagnostics, Vulkan probe and build/import tools.
- Clean the old private renderer cache on upgrade and invalidate its old renderer selections. Other renderers and generic external-plugin support remain available.

Existing content-management features and keyboard-opening fixes remain included. No world, mod, account or unrelated setting is intentionally deleted by this update.

## Downloads
- **Aerix-Launcher-1.3.3.apk** — full build with bundled Java runtimes; recommended for new installations.
- **Aerix-Launcher-1.3.3-noruntime.apk** — smaller build for users with Java runtimes already installed, or who prefer installing runtimes separately.

Download the APK directly; no Actions ZIP extraction is needed. Install over the current app. **Do not uninstall or clear app data.** Back up important worlds before upgrading.

## Validation and limits
The release is rebuilt with embedded version **1.3.3** (no-runtime edition **1.3.3-noruntime**) and Android version code **10303**. Publication verifies these values before attaching APKs.

The release passed launcher regressions, Android InputConnection tests with a recording game backend, both APK builds, native FPS tests and retired-renderer absence checks. These automated checks do not replace testing on the affected user's phone/keyboard. The bridge cannot read Minecraft's actual chat buffer or observe arbitrary game-side caret changes; this is not a claim of compatibility with every mod and keyboard.
