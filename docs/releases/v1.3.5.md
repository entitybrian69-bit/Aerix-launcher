# Aerix Launcher 1.3.5 — Official CurseForge access

- Build with the newly configured CurseForge API credential so Discover can use official access instead of depending on the unavailable public mirror.
- Retain 1.3.4's response parsing, credential-isolated mirror fallback, finite timeouts and shared Discover/modpack-installer routing.
- Preserve existing chat fixes and launcher features. RustGL remains removed. Social screens remain design-only.

## Live verification
[Live metadata check 39412436496](https://github.com/entitybrian69-bit/Aerix-launcher/actions/runs/39412436496) returned HTTP 200 and a valid list of 30 results for the official default Mods search. The keyless mirror still returned HTTP 503. Credentials were not printed or sent to the mirror.

This verifies official search from CI, not every content type, file download, network or phone. On-device search and installation still need confirmation.

## Downloads
Install the full APK for bundled Java runtimes, or choose the smaller no-runtime APK to reuse installed runtimes. Install over your existing Aerix app; **do not uninstall or clear data**.
