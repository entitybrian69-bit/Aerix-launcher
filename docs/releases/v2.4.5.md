# Aerix Launcher 2.4.5

**This release installs over 2.4.1 in place** and fixes the updater download bug that could abort at
the end with `"The update download is incomplete. Please retry."`

## What changed

- **Fixed incomplete-download failure at 100% (`FastDownload`):** When a chunk connection dropped or
  reset mid-transfer after writing part of its range, the retry re-counted those already-written
  bytes in the progress total, pushing the counted byte total above the APK size and failing the
  final verification check right near 100%. The range cursor now advances byte-for-byte with the
  written total, `probe()` retries transient failures before falling back, and the single-stream
  fallback resumes/retries across drops instead of failing on the first early close.
- **Double-signed permanently (carried forward from 2.4.4):** Carries both the current signing
  certificate and the retired certificate so installs on 2.4.1 (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`
  against single-signed builds) and 2.3.2 or older update straight over in place without an
  uninstall or lost worlds.

## What to expect

- **On 2.4.1:** installs over it in place and keeps all instances, worlds, mods, accounts, and
  downloaded runtimes.
- **On 2.4.2, 2.4.3, or 2.4.4:** installs over it too.
- **On 2.3.2 or older:** installs over it directly too, because it still carries the retired key.

## The signing trade, stated plainly

Every release from 2.4.4 on is signed with both keys, permanently. The retired key is public in
this repository (`tests/aerix_legacy.p12.b64`), which means anyone with repository access can build
an APK that installs over an existing launcher. See
[`docs/signing-policy.md`](https://github.com/entitybrian69-bit/Aerix-launcher/blob/v3_openjdk/docs/signing-policy.md)
for the full AOSP reasoning and rules that still hold.

## Downloads

Choose the full APK for an included Java runtime, or a `-noruntime` APK to download runtimes as needed.
Select `arm64-v8a` for 64-bit ARM devices, `armeabi-v7a` for 32-bit ARM devices, or the universal APK
for another supported architecture. Checksums are in `SHA256SUMS`.
