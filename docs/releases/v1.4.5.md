# Aerix Launcher 1.4.5 — 25 animated wallpapers

## Animations, next to the wallpapers

The Wallpapers page now has two buttons: **Wallpapers** and **Animations**.

- **Wallpapers** is the 25 photographic presets, exactly as they were.
- **Animations** is **25 animated scenes**, one for each of the same places — the lush cavern, the
  cherry grove, the sunset river, the Nether, the End, the deep ocean, the frozen peaks, the geode,
  the deep dark and the rest.

Each scene is its own world, not a photo with effects on top: a moving sky, its own light (a setting
sun, a moon, aurora ribbons, lava cracks breathing, an End portal swirl, a sculk pulse spreading
across the floor, crystal facets catching light, light shafts, drifting mist, surf and ripples on
water), three layered silhouettes that slide at different speeds so the scene has depth, and
particles matched to it.

All 25 are **drawn at run time**. They add nothing to the download, and they work on every Android
version the launcher supports.

## One switch still controls everything

The Motion button on this page and Animated theme in Settings remain the same switch: off, and the
scenes hold still as a painted frame; on, and they run. Each animation also brings its own accent
colour, so the interface takes on the scene's palette when you pick it.

## Installing

Install over your existing Aerix app; **do not uninstall or clear data**. Signed with the same key as
1.4.4, so it updates in place.
