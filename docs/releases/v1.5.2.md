# Aerix Launcher 1.5.2 — the renderer crash is fixed, and one APK again

## Why the game died at startup

```
UnsatisfiedLinkError: dlopen failed:
  /data/app/.../com.entitybrian.emesis.renderer-.../lib/arm64/libemesis_renderer.so not found
```

The launcher accepted an **installed Emesis renderer plugin** as the selected renderer even though
that plugin does not actually package `libemesis_renderer.so` for this device. Setting up the
renderer passed that path to LWJGL, and the missing file killed the game the moment it created its
window — before the title screen.

Three changes, each of which would have prevented it:

1. **A plugin is only accepted if the libraries it declares are really there.** Declared library
   names are checked on disk; a plugin that names something it does not ship is skipped instead of
   being offered. The failure now happens where it can do no harm.
2. **The launcher's own Emesis wins.** The launcher ships a complete, matched Emesis for every
   architecture it builds, so an installed Emesis plugin is ignored rather than shadowing it — the
   plugin being older, partial or built for another ABI no longer matters.
3. **A stale selection resolves instead of falling back silently.** If the saved renderer tag no
   longer leads to a usable plugin, an Emesis selection becomes the bundled Emesis rather than
   quietly dropping to another renderer — and a plugin whose GL library has gone is refused before
   LWJGL ever sees the path.

## One APK again

The two-file split is gone: `Aerix-Launcher-debug.apk` is a single file that installs on any phone,
64-bit or 32-bit.

The cost is size, and it is worth being plain about it: that one file carries **both** ARM sets of
native libraries, which is about 38 MB of the ~75 MB. The 52 MB download in 1.5.1 was only the
64-bit half of the same thing. A single APK for every device cannot be as small as a per-device one
without removing support for devices or renderers.

## Unchanged

Every renderer, every wallpaper, the twelve clips, the WebP photographs — all as they were.
