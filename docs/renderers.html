Renderers

Twelve ways to draw the same world

Android GPUs, drivers and game versions disagree about almost everything. Aerix ships several translation layers so a phone that will not run one renderer can still run the game.

◆

Start with Emesis. It is bundled, needs no plugin APK, and works on the widest range of devices. Change the renderer per instance, not globally, so a game that needs Zink does not force everything else onto it.

New in 1.5.5

A missing library no longer kills the launch

A renderer names the OpenGL library LWJGL should load. When that library is not on disk — a plugin APK pointing at a path that does not exist, most often — the game used to die during startup, before the renderer picker was reachable.

Checked first

The library is resolved before the JVM starts, so a bad path is caught while there is still a launcher to say so.

Bundled Emesis

The replacement is the Emesis that ships with the launcher — the same translation layer most plugins provide — so you stay on the renderer you meant to use.

Then GL4ES

If Emesis is the one that failed, GL4ES takes over rather than the game closing.

!

If a game still refuses to start: open the instance settings, try another renderer, and lower the resolution. If you have an Emesis plugin APK installed, remove it — the launcher already carries its own.

Choosing

A short decision tree

  1. Does it start on Emesis?

    Stop there. The default is the default because it works on the most hardware.

  2. Black screen, crash on launch, or unreadable graphics?

    Try Zink if your phone has a recent Vulkan driver, otherwise OpenLTW for modern versions.

  3. Running something old — 1.8 to 1.16?

    Zink (Legacy) or GL4ES, and expect to lower the resolution.

  4. Modded, with graphics mods?

    MG-ES or Zink if the GPU is capable; shaders and Sodium-style mods are where renderer choice matters most.

  5. Nothing works?

    Turn the resolution down before changing anything else. It fixes more launches than any renderer swap.
