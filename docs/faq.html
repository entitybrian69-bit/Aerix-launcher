FAQ

Questions people actually ask

The short answers first; the awkward ones with a link to the page that covers them properly.

Is Aerix Launcher free?

Yes. There is no paid tier, no subscription and no ad. The launcher has no account of its own — you sign in with the Minecraft account you already have, or play offline.

Do I need to own Minecraft?

To play online on a Microsoft account, yes — the launcher signs in to your existing copy, it does not provide the game. Offline accounts work for testing packs and playing alone, exactly as they do in the desktop launcher.

Which file do I download?

For nearly every phone made since 2016, arm64-v8a. For an older 32-bit phone, armeabi-v7a. If you are not sure, the universal build works on everything and is bigger because it carries every architecture.

Will I lose my instances when I update?

No, as long as you install the new APK over the old one. Uninstalling first deletes the launcher's storage, which includes your instances, worlds, accounts and wallpapers. The in-app updater updates in place.

The game will not start. What do I do?

Change the renderer for that instance first — the default, Emesis, works almost everywhere, but a phone with a strong Vulkan driver may prefer Zink, and old versions often want GL4ES. If that does not help, lower the resolution and give the instance more memory. The renderer page has a short decision tree.

Does it support mods and shaders?

Yes. Choose Fabric, Forge, NeoForge or Quilt when you create the instance, then install mods from the built-in browser or drop them into the instance folder. Shaders need a capable GPU and the right renderer — that is where MG-ES or Zink earn their place.

Which Android versions and devices are supported?

Android 6.0 and newer, on both 64-bit and 32-bit devices. There is no device allowlist: the launcher runs where the GPU and drivers allow it, which is why there are so many renderers.

Is my Microsoft login safe?

The sign-in happens with Microsoft through the usual flow, and the token is stored on your device, in the launcher's own storage. The launcher sends nothing about you anywhere except the login you choose — there is no telemetry and no analytics.

Can I import my existing worlds and controls?

Yes. Worlds go into the instance's saves folder, and control layouts are plain JSON that import from the controls editor, including layouts from other launchers.

How do I switch accounts while playing?

Open the in-game menu and tap your name under the character. Pick the account and confirm — the game restarts and comes back signed in as them. A running game keeps the session it launched with, so the restart is the switch.

Where do the files live?

In the launcher's private storage on your device: instances, worlds, mods, Java runtimes and accounts. Nothing is uploaded; if you want a copy, the launcher's folders are reachable from its own file browser.

Why is the download so large?

The full build carries a Java runtime so the game can start without downloading anything else, plus native libraries for the architectures it supports. The no-runtime build is much smaller and fetches Java on first launch.

Still stuck?

Open an issue with your device, the instance's version and loader, the renderer, and the last thirty lines of the log. That is enough to answer almost anything.
