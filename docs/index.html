Renderers

Picked per version, not per launcher

Aerix bundles MobileGlues for Minecraft 1.17+, two VGPU options for 1.16.5 and older, and chooses the right renderer for each version by default — with every option still one tap away.

  • LTW for 1.17+ and LTW Legacy for 1.8–1.16.5, both built from source in the repository
  • GL4ES, VirGL, Zink-class and Mesa backends
  • Vulkan driver and graphics API chosen per instance

Install

Three steps to play

  1. 1

    Download the APK

    The button at the top always points at the newest release. Release builds are the ones to keep; the smaller no-runtime build downloads the Java runtime on demand.

  2. 2

    Allow the install

    Android will ask to allow installing apps from unknown sources the first time. Aerix is signed with the project's own release key.

  3. 3

    Pick a version and play

    Create an instance, add an offline account or sign in with Microsoft, equip a skin and cape, and launch. Requires Android 8.0+, best on 4 GB RAM or more.

A note on packages

The release build installs as net.kdt.pojavlaunch. The earlier test builds used the .debug package, so the two can sit side by side — but their instances and game data do not carry over, and an installed original PojavLauncher has to be removed first because the signature differs.

FAQ

Questions people actually ask

Is it free?

Yes. Aerix is open source under GPL-3.0, with no ads, no telemetry and no paid tier. Downloads come from GitHub Releases.

Do I need a CurseForge API key?

No. The content browser works out of the box: it falls back to a public mirror when no key is configured, and an own key can be set in Settings if you have one.

Which Minecraft versions work?

The version list inside the launcher is the complete Mojang manifest, and the downloader lists every version the source (Modrinth or CurseForge) knows. Renderers are chosen to match the version you launch.

Will it run on my phone?

Android 8.0 or newer, and 4 GB of RAM or more is the comfortable spot. Layouts, accounts, skins and the launch flow are tested on more than one device.

Is this an official Minecraft app?

No. Minecraft is a trademark of Mojang Synergies AB. Aerix Launcher is an independent project and is not affiliated with, endorsed by or associated with Mojang or Microsoft.

How do updates work?

Settings → About → Check for update asks the GitHub Releases API, compares your build and points you at the newest APK. No mystery JSON, no dead link.
