↓Download the latest APK
  1. 1

    Download the APK

    Take the full build unless you are short on space: it carries its own Java runtime. The no-runtime build is smaller and fetches the runtime on demand.

  2. 2

    Allow the install

    Android will ask to allow installing apps from unknown sources the first time. Aerix is signed with the project's own release key.

  3. 3

    Pick a version and play

    Create an instance, add an offline account or sign in with Microsoft, equip a skin and cape, and launch.

A note on package names

The release build installs as net.kdt.pojavlaunch. The earlier test builds used the .debug package, so the two can sit side by side — but their instances and game data do not carry over, and an installed original PojavLauncher has to be removed first because the signature differs.

Keeping it current

Aerix checks GitHub Releases for you: Settings → About → Check for update compares your build and points you at the newest APK. This page's download button asks the same API, so it never hands out an old file.
