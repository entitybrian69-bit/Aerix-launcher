Install

About a minute, start to a world

Aerix is a plain APK, installed from outside the Play Store. Android will warn you once; that warning is normal for any app installed this way.

  1. Download the right file

    Almost every phone made since 2016 wants arm64-v8a. If yours is older, take armeabi-v7a; if you are unsure, the universal build always works.

  2. Allow the install

    Your browser will ask whether to allow installs from this source. Allow it once, then tap the downloaded file.

  3. Add an account

    Open the launcher, tap the avatar at the bottom of the rail, and sign in with Microsoft, Ely.by, or make an offline account.

  4. Create an instance

    Pick a version and a loader. For a first run, vanilla with no mods is the fastest way to find out whether the device and renderer are happy.

  5. Press play

    The first launch downloads the game and the Java runtime it needs. Later launches start straight into the game.

Which APK?

arm64-v8a recommended Aerix-Launcher-1.5.6-arm64-v8a.apk 72.0 MB 64-bit phones — nearly all of them armeabi-v7a Aerix-Launcher-1.5.6-armeabi-v7a.apk 72.2 MB Older 32-bit phones Universal Aerix-Launcher-1.5.6.apk 127.2 MB Every architecture — the safe fallback

The no-runtime build is smaller because it fetches Java on first launch instead of carrying it.

◆

Updating: install the new APK over the old one. Do not uninstall first — that deletes your instances, worlds, accounts and wallpapers. The in-app updater does this for you and picks the build that matches your device.

Requirements

What it needs

Android 6.0 or newer

Both 64-bit and 32-bit devices are supported, with a build for each.

About 2 GB of storage

More for modded instances — a big pack plus its Java runtime grows quickly.

2 GB of RAM, realistically 3+

Vanilla is comfortable on 2 GB; modpacks want more, and the launcher lets you allocate it per instance.

When something goes wrong

The four fixes that solve most launches

1. Change the renderer

Instance settings → renderer. Emesis by default; Zink or OpenLTW on newer phones; GL4ES for old versions. The full lineup →

2. Lower the resolution

It fixes more launches than any renderer change, and it is reversible.

3. Give it more memory

A pack that closes itself mid-load is usually short of heap, not broken.

4. Read the log

In-game menu → Log output, or the log in the launcher. The last line before the crash names the mod almost every time.
